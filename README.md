# BeyondQuantum: Introduction to Quantum and Research 2026
This repo contains the research project submissions for the [BeyondQuantum programme](https://thinkingbeyond.education/beyondquantum/) in 2026. It contains project on *Quantum Computing*, *Quantum Machine Learning* and *Foundations of Quantum Physics*. The accompanying research posters for each project can be found in the [BeyondQuantum Proceedings 2026](https://thinkingbeyond.education/beyondquantum_proceedings_2026/). 

For the individual research projects please navigate to the folder of each team. For research projects of past iterations of the *BeyondQuantum* programme please navigate to [BeyondQuantum 2025](https://github.com/ThinkingBeyond/ByondQuantum-2025) and [IQRG 2024](https://github.com/ThinkingBeyond/IQRG-2024).
